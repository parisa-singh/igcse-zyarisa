# Resources — IGCSE Site (canonical source)

> This file is the **single source of truth** for every resource used on `resources.html`
> and the subject pages. When resources change, update THIS file first, then propagate to
> the HTML. All links verified July 2026.
>
> **Rendering rules** (used on the site):
> - Tables use the `.resource-table` component (columns: Resource · Type · Access · Subjects · Notes).
> - Resource names are hyperlinks.
> - Access is a badge/pill: **green = Free**, **amber = Freemium**, **red = Paid**.
> - Rows sorted: Free → Freemium → Paid.
> - Subject pages show only the rows relevant to that subject.
>
> **Access labels:** Free = fully usable at no cost (free sign-up ok). Freemium = meaningful
> free tier, paid unlocks more. Paid = payment required, no useful free tier.
